# Code — Global Rainfall Prediction

This directory contains the implementation of the regional rainfall
prediction models and the trained model checkpoints used in the
Global Rainfall Prediction framework.

## 📂 Regional Models

The project contains four country-specific rainfall prediction agents:

- **China**
- **Nigeria**
- **South Africa**
- **Yemen**

Each country folder contains the corresponding preprocessing,
feature engineering, model training, evaluation, and trained model
files.
